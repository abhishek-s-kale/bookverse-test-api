# bookverse-test-api
A backend project to demo basic user registration login flow and adding books and their reviews in a specific manner

#summary of this project
- Clone this repository to your local
- make sure you have node installed on your machine
- run 'npm install' command from you machine
- configure the .env file properly with the parameters provided separately or as instructed below
- run 'npm run dev' to run the application locally
- make API calls from the Bruno API/ Postman file

#setup instructions

use below values in .env
PORT = 3000
MONGODB_URI = Mongo-url-provided-separately

-make use of bookverse.json which is the postman file
